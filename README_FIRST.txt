Collecta — Render + Neon deployment
See "Collecta - Free Deployment Guide (Render + Neon).pdf" for click-by-click steps.
Summary: 1) create a free Neon Postgres database and copy its connection string,
2) upload this whole folder to a new GitHub repository,
3) on Render choose New > Blueprint, connect that repository,
4) when asked, paste the Neon connection string as DATABASE_URL, and Deploy,
5) open the app URL and complete the first-time setup screen.
